# Project Summary: Web Analytics Customer Segmentation

## Objective
Segment online customers based on website behaviour, ecommerce activity, engagement, acquisition source, and conversion behaviour.

## Analytical Approach
1. Generate customer-level web analytics dataset.
2. Prepare behavioural features.
3. Standardize numerical variables.
4. Evaluate optimal K using elbow method and silhouette score.
5. Fit K-Means model.
6. Profile clusters.
7. Translate clusters into business actions.

## Business Value
- Improve conversion through targeted CRO actions.
- Increase remarketing efficiency.
- Identify high-value customer segments.
- Reduce spend on low-intent visitors.
- Support personalization and lifecycle marketing.
